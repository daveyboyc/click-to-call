Click-to-Call Smoke Test Page

Use this page while developing the Chrome extension. It contains realistic phone-number formats that should be detected, normalized to E.164, and relayed with the leading + preserved all the way to Android.

Expected pipeline behavior

  1. Extension detects a number in page text.
  2. Number is normalized to E.164.
  3. Relay request sends JSON with "number": "+...".
  4. Firebase forwards the same value in the FCM data payload.
  5. Android app opens tel:+... without dropping the plus sign.

Manual checks

  • Verify the extension turns detected numbers into clickable UI affordances.
  • Verify local-format numbers normalize using the configured default country.
  • Verify + remains present in logs, network payloads, push data, and the dialer URI.
  • If a number reaches Android without +, treat that as a release blocker.
