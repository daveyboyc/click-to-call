# Privacy Policy for Click to Call Effective date: 2026-03-12 Click to Call consists of a browser extension and an Android app that work together to send a phone number selected in the browser to the user's paired Android device. ## What data is used Click to Call uses the following data only to provide the core feature: - the phone number that the user clicks in the browser - a device pairing token used to route the request to the user's Android device - basic diagnostic and delivery information from the relay service ## How data is used This data is used only to: - send the selected phone number to the paired Android device - trigger a notification or dialer flow on that device - prevent abuse via basic rate limiting and request validation ## What Click to Call does not do Click to Call does not: - sell personal data - read or store full browsing history for marketing purposes - track unrelated page activity - use the clicked phone number for advertising ## Data sharing A clicked number and paired device token are sent to the configured relay service and then to Firebase Cloud Messaging so the message can reach the paired Android device. ## Data retention Operational logs and delivery metadata may be retained for debugging, reliability, and abuse prevention for a limited period. ## Security Reasonable steps are taken to protect relay and messaging traffic, but no internet-based system can be guaranteed 100 percent secure. ## User choices Users can: - disable the extension - remove the extension - uninstall the Android app - revoke or replace a device token by reinstalling or re-pairing ## Contact Support contact: davidcrawford83@gmail.com ## Changes This policy may be updated from time to time. The latest version should be published wherever Click to Call is distributed.
